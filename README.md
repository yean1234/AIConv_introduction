# AI융합학부 마을

한동대학교 AI융합학부 전공 소개 페이지. 설명회에 온 사람은 마을에 놀러 온 **손님**이고, 각 전공은 자기 마을을 가진 캐릭터가 맞이합니다. 섬 지도에서 마을을 골라 들어가면 마을 속 장소(섹션)를 둘러보며 전공 정보를 볼 수 있습니다.

| 마을 | 전공 | 주민 |
| --- | --- | --- |
| 하치와레 언덕 | GE 전공 | 하치와레 |
| 우사기 갈림길 | AI융합 전공 (5트랙) | 우사기 |
| 치이카와 풀밭 | 데이터 사이언스 전공 | 치이카와 |
| 마을 안내소 · 광장 게시판 | 학부 소개 · 학부 행사 | 세 친구 |

- 빌드 없음 — `index.html`을 브라우저로 열면 됩니다. (GitHub Pages 등 정적 호스팅 그대로 가능)
- 개발 서버: `npm install` 후 `npm run dev` (Vite, 저장하면 자동 새로고침)
- 디자인 기준: [`design-system/chiikawa-village/MASTER.md`](design-system/chiikawa-village/MASTER.md)
- 내용: `2026-2_12_AICnv.pdf` 요람 기준

## 파일

| 파일 | 역할 |
| --- | --- |
| `data.js` | 과목 DB(`COURSES`)와 전공별 내용(`RECORDS`) — 내용 수정은 여기서만 |
| `village.js` | 마을 이름·캐릭터·대사·장소 이름 — 화면 라벨 수정은 여기서만 |
| `app.js` | 입장 게이트, 섬 지도, 라우팅(`#/ge`, `#/ai/ict` …), 마을 페이지 렌더링 |
| `styles.css` | 스타일 |
| `assets/chars/` | 캐릭터 이미지 (투명 배경 PNG) |

> 캐릭터 이미지는 먼작귀(ちいかわ) 저작물입니다. 공개 URL로 배포하기 전에 사용 범위를 확인하세요.

## 학부 행사 추가

`data.js`의 `events` 레코드에 항목을 넣으면 광장 게시판에 표시됩니다.

```js
events: [
  { date: '2027.03.02', title: '전공 설명회', place: '뉴턴홀', desc: '세 전공 주임교수님 소개', tag: '설명회' },
],
```
